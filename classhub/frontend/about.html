About the Project

About ClassHub

A smart classroom management system built to bring students, class representatives, and administrators onto one connected platform.

Purpose

Why We Built ClassHub

College classrooms generate a constant stream of information — attendance records, class notes, assignment deadlines, project briefs, semester rankings, and notices. Traditionally, this information is scattered across WhatsApp groups, printed notices, and spreadsheets, making it difficult for students to stay organized and for administrators to maintain accurate records.

ClassHub solves this by providing a single, secure, role-based platform where every stakeholder — Student, Class Representative, and Admin — has exactly the tools they need to do their part effectively.

User Roles

Three Roles, One Platform

Student

Registers, logs in with Roll Number, views schedule, attendance %, notes, assignments, projects, rankings, and notices. Can edit their own profile and submit feedback.

Class Representative

Takes attendance twice daily (10 AM & 2 PM), uploads notes, assignments, projects, and notices, and manages class strength.

Admin

Has full system access — manages students and CRs, uploads attendance percentages and rankings, manages notices, and views feedback.

Developer

Development Team

ClassHub was developed as a full-stack college project demonstrating practical use of Node.js, Express.js, MySQL, JWT authentication, and modern responsive frontend design with Bootstrap 5. The project follows industry-standard practices including password hashing, role-based authorization, input validation, and clean RESTful API design.
